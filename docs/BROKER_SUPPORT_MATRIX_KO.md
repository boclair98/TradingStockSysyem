# 증권사 지원 및 연결 매트릭스

## 실주문 변환 코드가 구현된 어댑터

공개 배포의 자동화와 외부 주문 전송은 Paper-only로 잠겨 있습니다. 아래 어댑터는 코드·고정 응답 테스트 범위이며, 실제 주문 전송은 증권사 운영 승인, 고정 출발 IP, PostgreSQL 동시성 검증과 모든 release gate 승인 전에는 사용할 수 없습니다.

| 증권사 | 인증 | 계좌 확인 | 시세·호가 | 주문·취소 | 체결대사 |
|---|---|---|---|---|---|
| 토스증권 | OAuth2 Client ID/Secret | 계좌목록 자동 선택 | 가격·호가 | SOR·DAY 현금주문 | 주문상태 조회 |
| 한국투자증권 | OAuth2 App Key/Secret | 계좌번호·상품코드 입력 | KRX·NXT·통합 | 현금주문·취소 | 당일 주문체결 조회 |
| 키움증권 | OAuth2 App Key/Secret Key | `ka00001` 자동 조회 | `ka10001`·`ka10004` | `kt10000`·`kt10001`·`kt10003` | `ka10076` |

각 사용자는 자신의 증권사 키를 직접 등록합니다. 자격증명은 사용자별 AES-256-GCM으로 암호화하며 로그·브라우저 재표시·GitHub에는 남기지 않습니다.

## 다음 연동 후보

- [LS증권 Open API](https://openapi.ls-sec.co.kr/): OAuth, 시세, 주문 API를 제공하지만 이 저장소에서는 아직 실주문 어댑터를 노출하지 않습니다. 공식 계약조건, TR별 모의/실전 검증, 체결대사까지 완료한 뒤 활성화해야 합니다.
- 그 외 증권사: 개인/법인용 공식 주문 API, 서버 호출 허용, 고정 출발 IP 정책, 제3자 서비스에서의 키 보관·주문 중계 허용 여부를 먼저 확인해야 합니다.

공식 주문 API가 없는 증권사를 화면에 “지원”으로 표시하지 않습니다. HTS 화면 자동화, 비공개 API 호출, 사용자 비밀번호 수집은 사용하지 않습니다.

## 운영 경계

이 모듈은 다중 증권계좌 주문 라우터입니다. ATS 거래소 코어는 증권사 회원 OMS/FIX 게이트웨이, 독립 호가장·체결엔진, 시장감시, 청산·결제 연결을 사용하므로 개인 증권사 API 라우터와 분리 배포해야 합니다.
