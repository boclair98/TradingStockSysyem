# 거래소 납품 준비 갭 매트릭스

## 현재 판정

**Engineering Evaluation Build — 운영시장 사용 불가**

현재 저장소는 매칭 규칙·회원 게이트웨이·위험통제·저널 복구를 평가할 수 있는 제품 기준선입니다. 금융기관이 PoC 또는 기술실사를 시작할 수 있는 형태이지만, 금융위원회 인가·회원사 적합성 인증·시장감시·청산결제·이중센터 성능인증 없이 실제 시장에 투입하거나 “거래소 완제품”으로 판매해서는 안 됩니다.

금융위원회는 ATS 본인가 심사에서 법인격·자기자본·인력·물적설비·사업계획·건전경영·이해상충 방지·대주주 요건을 확인했습니다. 또한 복수시장 운영에는 최선집행, 동일 가격변동폭과 시장안정장치, 시장감시 및 T+2 청산결제가 함께 적용됩니다.

- 금융위원회 ATS 본인가 자료: <https://www.fsc.go.kr/no010101/83953>
- NEXTRADE 규정: <https://www.nextrade.co.kr/menu/regulation01/menuList.do>
- 국가법령정보센터 자본시장법: <https://law.go.kr/LSW/lsInfoP.do?lsiSeq=284145>

## 구매 가능한 제품으로 만들기 위한 입력

API 키보다 먼저 아래 자료가 필요합니다.

1. 대상 기관의 회원 주문·정정·취소·세션·Drop Copy 프로토콜 명세
2. 상품 마스터·시장상태·호가·체결·권리변동 데이터 라이선스와 포맷
3. 시장감시 및 규제 보고 항목, 보존기간, 제출 형식
4. 청산·결제·대사·결제불이행 인터페이스 계약
5. 예상 회원 수, 종목 수, 평균/피크 msg/s, 허용 p99.99 지연
6. RTO/RPO, 센터 구성, 전용망, PKI/HSM, 시각동기화 요구
7. 승인된 업무규정과 회원사 적합성 테스트 케이스

이 입력이 확보된 뒤에야 구현 완료와 운영 인증을 구분해 견적·납기·인수기준을 확정할 수 있습니다.
